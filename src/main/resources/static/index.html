📖 下游系统接入指南

1 调用 GET /api/snapshot/jobs/config/{configId}/latest 获取最新成功快照的 batchId 和 snapshotLsn 2 订阅 {Topic}_ALL，消费 Header X-Snapshot-Batch-Id = batchId 的全部消息，直到收到 X-Snapshot-Status: END 3 切换到原增量 Topic，跳过 LSN <= snapshotLsn 的消息，之后正常消费 4 全量消息的 op="r"（read），增量为 c/u/d（create/update/delete），可据此区分处理
